About
Zero dependencies · own JIT · exact int64Sıfır bağımlılık · kendi JIT'i · tam int64

As simple as Python. As fast as native code.Python kadar sade. Native kadar hızlı.

A general-purpose language that reads like Python and runs on a three-tier JIT it carries itself — no LLVM, no runtime to install. Batteries from signals to deterministic RNG are in the language, so it's as at home in a game loop as in a tool or a server. Python gibi okunan, kendi taşıdığı üç-katmanlı JIT ile çalışan genel-amaçlı bir dil — LLVM yok, kurulacak runtime yok. Sinyallerden deterministik RNG'ye kadar dilin içinde gelen özelliklerle bir oyun döngüsünde de bir araçta ya da sunucuda da rahat.

Install & runKurulum & çalıştırma

Install once, then run your files — the same two steps as Python. There is no build or compile step per program: lovax game.lov is to Lovax what python app.py is to Python. Bir kez kur, sonra dosyalarını çalıştır — Python'daki aynı iki adım. Program başına derleme adımı YOK: lovax game.lov, Lovax'ta python app.py'nin karşılığıdır.

1. Install1. Kur — the installer downloads the prebuilt binary for your platform onto your PATH. No compiler.kurucu, platformunun hazır binary'sini indirir ve PATH'e koyar. Derleyici gerekmez.

shell

irm https://raw.githubusercontent.com/uixova/lovax/main/install.ps1 | iex        # Windows

2. Run2. Çalıştır — point lovax at a file, or launch the REPL. That's the whole workflow.lovax'ı bir dosyaya yönlendir ya da REPL'i aç. Tüm akış bu.

lovax                  # interactive REPL

lovax update           # self-update to the newest release

Kaynaktan derlemek opsiyoneldir — CPython'ı kendin derlemek gibi, betik çalıştırmak için yapılan bir şey değil. Tek, bağımlılıksız bir C++17 komutu; sonrasında yine sadece lovax file.lov.

DivisionBölme

/ is true division (always a float) and // is floor division — the split Python 3 and Lua 5.4 make, so 1 / 3 is never 0. / gerçek bölme (her zaman float), // ise taban bölmesi — Python 3 ve Lua 5.4'ün yaptığı ayrım, böylece 1 / 3 asla 0 olmaz.

operators.lov
say 7 / 2        # 3.5   — true division, always a float
say 7 // 2       # 3     — floor division (toward -inf)
say -7 // 2      # -4
say 7 % 2        # 1     — floor modulo:  (a // b) * b + a % b == a
say 2 ** 10      # 1024  — power (right-associative)

say [1, 2] + [3]         # [1, 2, 3]
say "cat" in "concat"    # true
say 4 in range(0, 10, 2) # true

Comparison is deep: [1,[2]] == [1,[2]] is true. Logic (and or not) short-circuits; falsy values are null false 0 "" [] {}. Karşılaştırma derindir: [1,[2]] == [1,[2]] sonucu true. Mantık (and or not) kısa-devre yapar; yanlış sayılanlar: null false 0 "" [] {}.

Null safetyNull güvenliği

?. reads a field only when the value isn't null (otherwise the chain is null), and ?? supplies a fallback — together they replace a pile of guards. ?. bir alanı yalnızca değer null değilken okur (aksi hâlde zincir null olur), ?? ise bir yedek verir — birlikte bir yığın kontrolün yerine geçerler.

null-safety.lov
struct Node:
    value = 0
    next = null              # a field that may be null

set tail = Node(2, null)
set head = Node(1, tail)
say head.next?.value ?? -1   # 2   — next exists
say tail.next?.value ?? -1   # -1  — next is null, so the chain is null
say has(map, "key")          # test a map key without throwing

FunctionsFonksiyonlar

Declared with fn. First-class values that close over their scope, take default parameters, and return with return. Arity is strict. fn ile tanımlanır. Kapsamlarını kapatan, varsayılan parametre alan ve return ile dönen birinci-sınıf değerler. Argüman sayısı katıdır.

functions.lov
fn heal(target, amount = 10):        # default parameter
    return "{target} +{amount} hp"
say heal("hero")                     # hero +10 hp
say heal("hero", 25)                 # hero +25 hp

fn make_counter():
    set n = 0
    fn tick():
        n += 1            # closes over n, updates it
        return n
    return tick
set next = make_counter()
say next()   # 1
say next()   # 2

Anonymous & arrowAnonim & ok

Functions are values, so they pass into higher-order builtins like filter. A single-expression body can use the arrow form. Fonksiyonlar birer değerdir, filter gibi üst-düzey yerleşiklere geçebilirler. Tek-ifadelik gövde ok formunu kullanabilir.

lambdas.lov

Structs & enumsStruct & enum

A struct groups typed fields with methods; this is implicit. Fields are unboxed inline values, so an entity.x update allocates nothing — the property that makes entity loops fast. struct tipli alanları metotlarla gruplar; this örtüktür. Alanlar kutulanmamış satır-içi değerlerdir, yani entity.x güncellemesi hiç allocation yapmaz — entity döngülerini hızlı kılan özellik.

entity.lov
struct Player:
    hp = 100
    name = "hero"
    fn hurt(amount):          # 'this' is implicit
        this.hp -= amount
    fn status():
        return "{this.name}: {this.hp} hp"

enum State: IDLE, WALK, ATTACK

set p = Player(80, "Aria")
p.hurt(30)
say p.status()                # Aria: 50 hp
say State.ATTACK              # 2

ErrorsHatalar

try / catch / finally, and throw for your own. finally always runs — even when a return or break leaves the block. try / catch / finally ve kendi hataların için throw. finally her zaman çalışır — bir return ya da break bloktan çıksa bile.

errors.lov
fn load(path):
    try:
        return file.load_data(path)
    catch e:
        say "could not load: {e}"
        return {}
    finally:
        say "load attempt finished"
!

Runtime errors are located and readable — [Runtime Error] line 4: division by zero — and an uncaught error exits non-zero, so scripts fail loudly, never silently. Çalışma-zamanı hataları konumlu ve okunur — [Runtime Error] line 4: division by zero — yakalanmayan hata sıfırdan-farklı çıkar, betikler sessizce değil sesli başarısız olur.

Coroutine

Cooperative coroutines drive AI, dialogue, and frame-spread work. spawn a function, resume it, and yield values back — resume can pass a value into the paused yield. İşbirlikçi coroutine'ler yapay zekâyı, diyaloğu ve kareye-yayılan işi sürer. Bir fonksiyonu spawn et, resume ile devam ettir, yield ile değer döndür — resume, duraklamış yield'e değer geçirebilir.

coroutines.lov
fn patrol(start):
    set n = start
    while true:
        yield n              # hand a step back to the caller
        n += 1

set guard = spawn(patrol)
say resume(guard, 10)        # 10
say resume(guard)            # 11
say co_status(guard)         # suspended

PerformancePerformans

Lovax compiles to bytecode on a computed-goto stack VM, then lifts hot loops to native x86-64 through a three-tier JIT — a register allocator, a tracing compiler, and an always-correct template fallback — all from scratch, no LLVM. Lovax, computed-goto yığın-VM'inde bytecode'a derlenir, sonra sıcak döngüleri üç-katmanlı JIT ile native x86-64'e taşır — register ayırıcı, izleyen (tracing) derleyici ve her-zaman-doğru şablon yedeği — hepsi sıfırdan, LLVM yok.

Two levers make tight loops fast: struct fields are unboxed inline values, and allocation sinking scalar-replaces short-lived temporaries — a tmp = [i, i+1, i+2] built and read each iteration never reaches the heap. The interpreter is always the oracle: every tier is verified bit-identical to it. İki kaldıraç sıkı döngüleri hızlandırır: struct alanları kutulanmamış satır-içi değerlerdir ve allocation sinking, kısa-ömürlü geçici nesneleri skalerle değiştirir — her iterasyonda kurulup okunan bir tmp = [i, i+1, i+2] heap'e hiç ulaşmaz. Yorumlayıcı daima referanstır: her katman ona bit-birebir doğrulanır.

Under the hoodKaputun altı

Lovax is one C++17 translation unit with no third-party code. Source flows through a short, legible pipeline — each stage a small header you can read end to end: Lovax, üçüncü-parti kod içermeyen tek bir C++17 derleme birimidir. Kaynak, kısa ve okunur bir hattan geçer — her aşama baştan sona okuyabileceğin küçük bir başlık:

  • Lexer → Parser turn .lov text into an AST, with located, fix-suggesting errors and a bounded recursion depth so pathological source can't smash the stack.Lexer → Parser, .lov metnini AST'ye çevirir; konumlu, çözüm-öneren hatalar ve sınırlı özyineleme derinliğiyle patolojik kaynak yığını çökertemez.
  • Compiler lowers the AST to bytecode for a stack VM; the VM runs it on a computed-goto dispatch loop.Compiler AST'yi yığın-VM bytecode'una indirir; VM onu computed-goto döngüsünde çalıştırır.
  • Three-tier JIT lifts hot loops to native x86-64 through its own encoder: a register allocator, a tracing compiler (with allocation sinking), and a template compiler as the always-correct fallback.Üç-katmanlı JIT sıcak döngüleri kendi encoder'ıyla native x86-64'e taşır: register ayırıcı, izleyen derleyici (allocation sinking'li) ve her-zaman-doğru yedek şablon derleyici.
  • Garbage collector is tracing and incremental, with sub-millisecond pauses and a write barrier — tuned for a frame budget.Çöp toplayıcı izleyen ve artımlıdır; milisaniye-altı duraklar ve bir write-barrier ile — kare bütçesine göre ayarlı.

Values are NaN-boxed into 8 bytes (a 16-byte fallback exists for platforms without the pointer guarantee), and integers stay exact 64-bit. Every JIT tier is proven bit-identical to the interpreter across a differential matrix, sanitizers, and an adversarial torture suite. Değerler 8 bayta NaN-boxlanır (pointer garantisi olmayan platformlar için 16-baytlık yedek vardır) ve tam sayılar tam 64-bit kalır. Her JIT katmanı yorumlayıcıya bit-birebir kanıtlanır: differential matris, sanitizer'lar ve adversarial işkence takımıyla.

The JIT, GC and value model were studied, not copied, from the Lua 5.5 and CPython source trees — reading how they solve a problem, then writing our own zero-dependency answer. LuaJIT is the north star for the tracing JIT. JIT, GC ve değer modeli Lua 5.5 ve CPython kaynaklarından kopyalanmadan, incelenerek yapıldı — bir problemi nasıl çözdüklerini okuyup kendi bağımlılıksız cevabımızı yazarak. İzleyen JIT için kutup yıldızı LuaJIT.

EmbeddingGömme

Lovax is built to be hosted. A C++ façade and a stable C ABI (lovax.h) let an engine register native functions, expose owning userdata with finalizers, and hold values as roots across collections. Lovax gömülmek için tasarlandı. Bir C++ cephesi ve kararlı C ABI (lovax.h), bir motorun native fonksiyon kaydetmesine, finalizer'lı sahip-userdata sunmasına ve değerleri toplama boyunca kök olarak tutmasına izin verir.

host.cpp
Lovax vm;
vm.registerFn("engine_time", [](Args a){ return Value::number(now()); });
vm.run("say \"frame at {engine_time()}\"");

FFI is gated behind --allow-ffi and denied under the sandbox, so embedding never widens the trust boundary by accident. FFI, --allow-ffi arkasındadır ve sandbox altında reddedilir, gömme güven sınırını kazara genişletmez.

About

About LovaxLovax hakkında

Lovax is a from-scratch, general-purpose language, written in modern C++17 with zero third-party dependencies — as simple as Python to write, close to native in speed to run. It's a comfortable fit for tools, servers, scripts and game code alike, and its batteries (signals, deterministic RNG, save files, a capability sandbox) make it especially strong for games. It is developed in the open, correctness-first: nothing merges unless the whole test battery is green, and the interpreter is always the reference every faster path must match. Lovax, modern C++17 ile sıfır üçüncü-parti bağımlılıkla sıfırdan yazılan genel-amaçlı bir dildir — yazması Python kadar sade, çalışması native'e yakın hızlı. Araçlar, sunucular, betikler ve oyun kodu için eşit derecede rahat; içindeki özellikler (sinyaller, deterministik RNG, kayıt dosyaları, yetenek sandbox'ı) onu özellikle oyunlarda güçlü kılar. Açıkta, önce-doğruluk ilkesiyle geliştirilir: tüm test bataryası yeşil olmadan hiçbir şey birleşmez, ve yorumlayıcı her hızlı yolun eşleşmesi gereken referanstır.
